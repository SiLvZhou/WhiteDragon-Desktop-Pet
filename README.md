# 白龙娘 · Codex 桌面陪伴

一只全身白发、紫瞳、带龙角、翅膀与尾巴的小龙娘，住在 Windows 桌面上。她可以回应点击与拖动，播放中文语音，在你使用 Codex 时呈现工作状态，并展示当前账户的额度、Token 用量和未读完成对话。

本仓库用于发布 **Windows 便携程序与使用说明**。仓库文件仅包含这份 README；程序包放在 Releases，不上传本项目的开发源码、Git 历史、制作工程或个人配置。

> 当前版本：**v0.1.0 · Windows x64 · 2026-10-26**。首次公开便携发行，自动走动暂未开放。

## 下载与启动

**[下载最新便携版](https://github.com/SiLvZhou/WhiteDragon-Desktop-Pet/releases/latest)**

1. 打开上面的 Releases 页面，下载 `WhiteDragon-v0.1.0-win32-x64-portable.zip`。
2. 右键 ZIP →「全部解压」，选择一个有写入权限的本地文件夹。
3. 进入解压后的 `WhiteDragon-v0.1.0-win32-x64-portable` 文件夹，双击 **`WhiteDragon.exe`**。
4. 如需显示 Codex 额度与对话状态，请在同一 Windows 用户下安装并登录 Codex 桌面应用。
5. 右键角色或系统托盘图标，打开设置、陪伴手册或退出。

**不需要安装 Node.js、Python、动画模型或语音生成环境。** 程序已包含运行时和本地动画、语音。请保留整个解压目录，不能只复制 EXE，也不要直接在压缩包预览窗口中运行。

Release 页面自动生成的 `Source code (zip)` / `Source code (tar.gz)` 只会包含本仓库的说明文档，**不是可运行程序**。请下载上面指定名称的便携 ZIP。

发布包同时提供 `SHA256SUMS.txt`，可用 PowerShell 校验下载是否完整：

```powershell
Get-FileHash -Algorithm SHA256 .\WhiteDragon-v0.1.0-win32-x64-portable.zip
```

将结果与同一 Release 中 `SHA256SUMS.txt` 的值比较。校验一致后再解压。

## Codex 工作陪伴

白龙娘读取当前用户本地可用的 Codex 对话活动，按思考、执行任务、查资料、修改文件和回复完成等状态切换表现。工作动画包含记笔记、敲键盘、翻资料等动作，并在工作结束时播放收尾。

可以使用两种跟随方式：

- **自动跟随**：从最近最多 40 个未归档的本地主聊天中选择当前活动。
- **固定聊天**：在「正在陪伴的对话」中选择一个聊天，关注它的状态。

这是活动状态联动。她不会理解并回答每一句聊天，不会读取并朗读模型内部思考，也不会代替你给 Codex 发送提示词。仅在远端存在、尚未写入当前电脑的聊天，或超出最近列表范围的聊天，可能不会出现在桌宠中。

对话活动约每 **2 秒**刷新，对话列表约每 **15 秒**刷新。实际效果受本机记录、Codex 版本及登录状态影响。

## 额度与 Token 统计

顶部卡片每 **5 秒**在两组信息之间轮播，鼠标悬停或键盘聚焦时暂停；点击右侧箭头可手动切换。

| 页面 | 展示内容 |
| --- | --- |
| 额度 | 5 小时窗口剩余额度、本周剩余额度，以及各自的重置时间 |
| Token | 当前账户累计 Token、今日 Token；悬停查看完整数字 |

额度使用已登录官方 Codex CLI 的 app-server 只读接口，约每 **120 秒**刷新，也支持手动刷新与重连。额度属于 **Codex**，不是 ChatGPT 网页对话额度。

Token 约每 **30 秒**刷新，采用与当前 Codex 个人资料页面相同的账户统计来源，不用本机聊天日志的合计替代账户累计值。今日数据按北京时间日期匹配；服务端尚未返回当天统计时显示 `—`，不会拿昨天的数据充当今天。

额度或用量读取失败、登录失效、返回格式变化时，会显示未知或按时效处理已有读数，不伪造百分比。账户统计可能延迟，点击刷新不代表服务端立即补齐。

**兼容性说明**：额度使用官方 app-server；个人资料统计与原生未读标记的读取包含对当前 Codex 客户端实现的适配，并非全部属于公开稳定接口。Codex 后续升级可能需要桌宠同步更新。

## 未读完成对话提醒

进行中的对话优先显示为普通文字，例如「整理项目 正在思考中」。有多个任务同时进行时，优先显示最近开始的轮次。

空闲时，气泡每 **5 秒**轮播一个 Codex 自身标记为未读的已完成对话。只有这些完成项提供点击跳转链接；名称显示前 6 个可见字符。悬停、键盘聚焦或播放互动台词时暂停切换。

点击后通过系统注册的 `codex://threads/…` 链接打开对应聊天。已读与未读状态以 Codex 为准：直接在 Codex 中阅读后提醒会同步消失，重新标记未读后可以再次出现。桌宠不修改 Codex 的阅读标记；系统打开链接失败时也不会主动清除提醒。

## 动画与动作分组

默认使用 **720 × 720 透明全身连续动画**，保留龙角、翅膀、尾巴、裙摆、双脚及工作道具。动画整体按约 24 fps 制作，具体帧数和时长以素材为准。当前公开包保留原始审核文件，没有缩小画布、降帧或重新编码已通过动画。

### 原版 25 个动作

原版动作始终作为独立组保留，包含自然待机、招手、灵感、得意、贴贴、傲娇、困倦、庆祝、比心、额度查看、工作、拖动、落地等表现。工作动作另有循环衔接资源，以支持持续工作与结束收尾。

可以在快捷菜单或陪伴手册中逐一手动查看，实际动作名称以程序中的图鉴为准。

### 已审核的 3 个新增动作

| 动作 | 说明 | 触发方式 |
| --- | --- | --- |
| 低头戴皇冠 | 低头配合戴上皇冠的完整透明动画 | 「新增动作」手动播放 |
| 小翅膀飞冠 | 小翅膀参与皇冠互动的完整透明动画 | 「新增动作」手动播放 |
| 双指拎起 | 从上方以两根手指轻轻拎起后颈的悬空动作 | 手动预览，或与原拖动姿态交替 |

启动后首次拖动使用双指拎起，下一次使用原拖动动作，之后交替。同一次拖动过程中保持当前选择，松开后播放落地。

两版皇冠仅供手动播放，不进入自动待机池。未通过审核的走路草稿与本地试片不包含在公开包中；**自动走动当前停用**。本地开发目录中保留的试片不代表公开功能已经完成。

设置中还保留原图集模式及其八种待机小动作，包括伸懒腰、左右张望、扇翅膀、摸龙角、抱尾巴、打瞌睡、开心轻晃、乖巧点头。该模式使用透明姿势图与程序运动，不是 Live2D / 3D 模型，也不等同于默认的逐帧高清动画。

## 中文语音

内置 **11 段独立 MP3**，使用温柔女声、正常语速与自然音高，覆盖问候、摸摸、跳舞、等待和完成提醒。

- 语音已预先生成，运行时只播放本地文件。
- 不需要语音服务账户，不调用 Windows 系统朗读。
- 同类互动会轮换台词，气泡文字与语音对应。
- 一段语音播放期间再次点击，不会叠加声音。
- 关闭语音或把音量调为零，会立即停止当前声音。
- 「对话进度语音」控制思考与回复完成的提示；首次连接或切换聊天时不会补播旧事件。
- 随机待机动作保持安静。

## 随 Codex 启动与退出

设置中的「随 Codex 启动和退出」控制隐藏的本地跟随监听。启用后，打开 Codex 可以带起桌宠；退出 Codex 后，桌宠通常在约 **2–4 秒**内正常保存并关闭。最小化 Codex 时桌宠继续显示。

**首次解压运行不等于已经创建 Windows 登录启动入口。** 如需在下次 Windows 登录后也自动等待 Codex，可在便携目录中右键以下脚本，选择「使用 PowerShell 运行」，或在便携目录打开 PowerShell 执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\resources\app.asar.unpacked\scripts\windows\install-follow.ps1"
```

脚本为当前用户创建 `WhiteDragon-Codex-Follower.lnk` 登录入口，不要求管理员权限。移动程序目录后，请从新位置重新运行该脚本，更新入口指向。

关闭「随 Codex 启动和退出」后，监听会结束，可独立运行桌宠。在 Codex 仍打开时从菜单手动退出桌宠，本次 Codex 运行期间不会反复把它拉起。跟随功能针对 Codex 桌面应用，不把 VS Code 插件或桌宠自己的 CLI 连接进程视为 Codex 主窗口。

## 本地设置与隐私

设置及位置保存在当前 Windows 用户的 `%APPDATA%\白龙娘\`，以 Electron 实际 userData 目录为准。便携是指程序解压可运行；设置不会全部写回 EXE 所在目录。

- 读取当前用户可用的 Codex 对话活动、标题和原生未读状态，用于本地展示。
- 账户认证由已登录的官方 CLI 管理；桌宠不读取 `auth.json` 的内容。
- 读取账户统计时，认证仅在主进程内存中临时用于固定的官方 HTTPS 地址；不写入发行包、日志或渲染页面。
- 本应用不把聊天内容上传到本项目作者的服务，不创建新对话，不发送提示词，不修改账户和聊天记录，不添加 Codex Hooks。
- 账户额度、用量查询会连接官方服务；本地动画和预录语音无需联网。
- 连接与查询不发起模型推理请求，不额外消耗推理 Token。
- 关闭监听后，可以继续使用普通桌宠互动。

发行包不包含制作者的账号、聊天记录、个人设置、访问令牌或生成模型。

## 常见问题

### 双击后找不到角色

先查看系统托盘是否已有白龙娘。尝试 `Ctrl + Alt + Shift + D` 恢复位置。如果已经打开旧版本，请先从它的菜单退出，再启动新版本。不要把不同版本的 EXE 和资源目录混放。

### 出现缺失文件或启动失败

确认已将 ZIP 完整解压，EXE 旁保留 `resources`、`locales`、DLL、PAK 等文件。重新校验 SHA-256；文件不完整时重新下载。不要只取 EXE，也不要使用仓库的 `Source code` ZIP。

### Windows 提示发布者未知

本发行版没有商业代码签名证书，Windows 可能显示未知发布者。请核对下载来源与 SHA-256，并按自己的判断决定是否运行。

### 额度、Token 或对话显示未知

确认 Codex 在同一 Windows 用户下正常登录、设置中启用了监听，并尝试手动刷新或重连。今日 Token 尚未同步也会显示 `—`。Codex 版本变化、网络、账户权限和本地记录缺失都可能影响读取。

默认从 `%LOCALAPPDATA%\OpenAI\Codex\bin` 发现 Codex CLI；特殊安装可通过 `CODEX_CLI_PATH` 指定 `codex.exe`。如设置了 `CODEX_HOME`，应用按该目录查找本地 Codex 数据。普通用户通常无需设置这些环境变量。

### 点击完成对话后没有跳转

需要系统已为 Codex 桌面应用注册 `codex://` 协议。可以先手动打开 Codex 并确认安装正常；当前发行只针对已验证的桌面客户端行为适配。

### 没有声音

检查设置中的语音开关、音量以及 Windows 音量混合器。用「听一听」逐句试听。对话进度提醒另有开关，首次连接不补播历史提醒。

### 为什么包仍然比较大

主要体积来自完整透明高清逐帧动画，以及内置的 Electron / Chromium 运行时。WebP 与 MP3 已压缩，重复套用 ZIP 对动画收益很小。本版通过移除未发布试片、制作参考资料、重复海报与演示附件，并仅保留简体中文、繁体中文、英文语言包来瘦身。

没有为了体积牺牲已审核动画的画质、帧数和透明边缘。进一步大幅缩小，通常需要另做低分辨率、低帧率或重新编码版本，并单独检查视觉效果。

### 如何退出、卸载和清理

退出使用角色或托盘的右键菜单。卸载前关闭随 Codex 跟随选项并退出程序，随后删除便携目录。

如果曾运行登录入口安装脚本，可按 `Win + R`，输入 `shell:startup`，删除其中的 `WhiteDragon-Codex-Follower.lnk`。若还需要清除名字、位置等设置，可在退出后删除 `%APPDATA%\白龙娘\`；这不会删除 Codex 本身的聊天记录。
